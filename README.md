# 开心消消乐 (极限倒计时生存挑战版) ⏰✨

一款纯网页端、支持大面积消除特效与极限倒计时生存挑战的经典消消乐小游戏。无需安装任何环境或依赖，浏览器双击即玩，亦可直接分享网页链接给朋友游玩！

---

## ⚡ 核心新玩法：极限倒计时生存模式 (Time-Attack Survival)

游戏现已切换为刺激过瘾的**时间生存挑战模式**：

1. **取消步数与目标分数限制**：
   - 玩家拥有无限步数，不再受 30 步或 3000 分所限；
   - 目标是挑战自己的反应极限，尽可能延长生存时间，冲击最高的**累计分数**！

2. **初始 15 秒倒计时**：
   - 玩家进入游戏后可以自由观察棋盘，在**做出第一次有效移动时正式启动 15 秒倒计时**；
   - 倒计时采用高精度毫秒级跳动，剩余时间低于 5 秒时会触发红色呼吸警报灯光！

   - **基础 3 消精确加时**：基础三消稳定增加 **1.0 秒**（恰好补偿快速思考移动）；
   - **多消与特效边际递增**：消除 4 块、5 块或触发爆炸激光时平滑递增加时，每次连锁连击小额奖励 `+0.2秒`；
   - **单次加时严格封顶**：无论触发多大范围的全屏大爆炸或激光，单次消除加时**最多严格封顶不超过 4.0 秒**，杜绝时间无限溢出！
   - 加时时，屏幕上方会伴随翠绿色的 `+1.0s ⏳` / `+2.5s ⏳` 悬浮光标跳动回血。

4. **倒计时归零立即结束**：
   - 一旦倒计时耗尽，游戏立即停止并弹出**挑战结算大奖章**；
   - 结算展示：**最终累计得分**、**生存坚持时长**、**最高连击记录**、**累计消块数**以及**荣誉大师称号**（消除新秀 / 敏捷挑战者 / 治愈手速大师 / 极光神级传说）。

## 💥 大面积消除与特效方块系统

| 匹配形状 | 生成特效方块 | 标志角标 | 触发消除威力 |
| :--- | :--- | :---: | :--- |
| **四连横线** | **横向直线消除** | `↔` | 贯穿全屏的高能青蓝激光，**消除整整一行** |
| **四连竖线** | **纵向直线消除** | `↕` | 贯穿全屏的高能青蓝激光，**消除整整一列** |
| **L 型 / T 型匹配** | **范围爆炸方块** | `💣` | 炽热冲击波大爆炸，**引爆周围 3×3 范围** |
| **十字型匹配** | **十字消除方块** | `✚` | 迸发双向强光，**同时消除所在整行和整列** |
| **五连直线 (横/竖)** | **同色魔力鸟 / 彩虹糖** | `🌈` | 极光魔力爆发，**全屏消除所有同类图案方块** |

### 🌟 双特效直接互换（超神组合技）
两个相邻特效方块直接交换，无需凑成三消即可触发大招：
- **直线 + 直线 (`↔`/`↕` + `↔`/`↕`)** ➔ 超级十字激光，消整行 + 整列！
- **炸弹 + 炸弹 (`💣` + `💣`)** ➔ 5×5 巨型大核爆！
- **直线 + 炸弹 (`↔`/`↕` + `💣`)** ➔ 3行 + 3列 超级十字光束全屏扫射！
- **同色 + 任意特效 (`🌈` + 特效)** ➔ 全屏同色方块瞬间变身为该特效并同时引爆！
- **同色 + 同色 (`🌈` + `🌈`)** ➔ 终极大招：全屏大清场，直接收获海量积分与超长加时！
- **同色 + 普通方块 (`🌈` + 普通方块)** ➔ 消除全场所有该颜色方块。

## ⚙️ 如何自定义调整倒计时与规则？

打开 [`game.js`](file:///D:/自己开发游戏/开心消消乐/game.js)，文件顶部的 `CONFIG` 对象参数支持任意调整：

```javascript
const CONFIG = {
  initialTime: 15.0,          // 初始倒计时 (秒)
  baseMatch3Time: 1.0,        // 普通 3 消基础加时：1.0 秒
  extraTileTime: 0.18,        // 超过 3 个方块，每个额外方块边际增加的时间 (秒)
  comboTimeBonus: 0.2,        // 每次连锁连击额外奖励时间 (秒)
  maxStepTimeBonus: 4.0,      // 单次单步消除严格封顶时间上限：最多不超过 4.0 秒
  maxTime: 60.0,              // 倒计时能量槽上限 (秒，防止无限溢出)
  gridSize: 16,               // 棋盘大小：16 × 16
  matchMin: 3,                // 最少消除方块数：3 个
  scorePerTile: 10            // 每个方块基础得分
};
```
修改保存后刷新网页即可生效！快来挑战你的极限手速与最高累计分吧！⏰🔥
