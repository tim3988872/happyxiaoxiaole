# 萌萌治愈消消乐 (Cozy Match-3 Game) ✨

一款唯美、温馨、治愈风格的纯网页端经典三消小游戏。无需安装任何环境或依赖，浏览器双击即玩，也可以直接把整个项目文件夹打包发送给朋友游玩！

---

## 🌟 核心特色与功能亮点

1. **纯前端零依赖**：
   - 基于原生 HTML5、CSS3 和 JavaScript 纯手工打造；
   - 采用相对路径管理资源，无论是双击本地 `index.html` 打开（`file://` 协议），还是上传到任何静态网页托管（GitHub Pages、Vercel 等），都能完美运行。

2. **唯美治愈系视听体验**：
   - **视觉设计**：温暖奶油与暖杏色渐变背景、柔和圆角卡片、细腻微阴影、全屏漂浮微光光斑与花瓣粒子；
   - **交互动效**：弹性选中微光、丝滑交换位移、炫彩消除爆破、掉落补位弹性动画、连击浮层 (Combo) 与飘字反馈；
   - **内置合成音效**：使用 Web Audio API 原生合成晶莹清脆的八音盒五声音阶和弦与风铃洗牌音，无需外部 MP3 文件，杜绝加载失败与跨域问题，支持一键静音。

3. **双重操作支持 (电脑 + 手机完美适配)**：
   - **电脑端**：支持鼠标点击选中相邻方块交换，亦可直接按住鼠标拖拽滑动；
   - **手机触屏端**：自适应屏幕宽度，支持手指滑动轻扫（Swipe）及点击两格快速消除，优化了移动端防滚动体验。

4. **完善的游戏机制**：
   - **智能死锁检测与自动洗牌**：若当前棋盘无任何可消除步骤，系统会自动唤起风铃洗牌动效并弹出温馨提示，绝不卡死；
   - **发呆贴心提示**：当玩家思考超过 6 秒未操作，可消除方块会自动呼吸闪烁，亦可随时点击「💡 提示」按钮；
   - **规格自由切换**：默认采用你指定的 **16 × 16** 超大巨幕模式，同时下拉菜单支持随时切换至 12×12、10×10 或 8×8（手机游玩超舒适）。

## 🚀 如何打开游玩？

### 方法一：直接双击（最推荐，简单快捷）
1. 打开文件夹 `match3-healing-game/`；
2. 直接双击 `index.html`，系统默认浏览器即可启动游玩！

### 方法二：分享给好友
- 将整个 `match3-healing-game` 文件夹压缩为 `.zip` 文件发送给好友；
- 好友解压后直接双击里面的 `index.html` 即可畅玩。

---

## 🎨 如何更换为你自己的图片？

图片素材存放在 `assets/images/` 目录下。

1. 准备好你喜欢的 4 张图片（JPG、PNG 或 WebP 均可）；
2. 将它们分别重命名为 `tile1.jpg`、`tile2.jpg`、`tile3.jpg`、`tile4.jpg`；
3. 直接覆盖替换 `assets/images/` 目录下的同名文件；
4. 刷新网页，游戏方块图案就会立刻变成你的专属素材！
   *(注：图片在游戏内会自动进行等比居中裁切并适配圆角，无需担心图片被压扁或拉伸拉扯)*

## ⚙️ 如何调整游戏难度与规则参数？

打开 `game.js` 文件，最顶部的 `CONFIG` 配置项清晰直观，你可以根据喜好自由修改：

```javascript
const CONFIG = {
  // 棋盘大小：默认 16 (即 16x16 棋盘)
  gridSize: 16,               

  // 初始步数：默认 30 步 (可改为 20、40 等)
  initialMoves: 30,           

  // 胜利通关目标分数：默认 3000 分
  targetScore: 3000,          

  // 基础消除得分：每消去一个方块的基础分
  scorePerTile: 10,           

  // 4连消 / 5连消额外奖励加分
  bonus4: 30,                 
  bonus5: 80,                 

  // 连击奖励系数步长 (x1.0, x1.5, x2.0...)
  comboMultiplierStep: 0.5,   

  // 发呆多少毫秒自动提示 (默认 6000 毫秒即 6 秒)
  idleHintDelay: 6000         
};
```
修改保存后，直接刷新浏览器即可生效！祝你玩得开心，收获满满的温暖与治愈能量！💖
